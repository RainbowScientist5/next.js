# Security Policy

## Supported Versions

This project is currently provided security updates for the following versions:

| Version | Supported      |
| ------- | --------------|
| 5.1.x   | ✔️             |
| 5.0.x   | ❌             |
| 4.0.x   | ✔️             |
| < 4.0   | ❌             |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via the issues tab or email the maintainers.  
You can expect a response within 48 hours.

When reporting, please include:  
- Steps to reproduce  
- Potential impact
- Your contact information for follow-up

Accepted vulnerabilities will be investigated and patched as soon as possible.  
If your report is declined, we will provide feedback with reasons.
